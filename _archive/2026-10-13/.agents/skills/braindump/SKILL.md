# braindump

Read [shared Codex workflow conventions](../../WORKFLOWS.md) before using this skill.

Capture promptly without turning the request into a planning interview. State an
interpretation if needed, preserve mixed-language wording, and do not invent detail.
Default destination is docs/codex/ideas/<slug>.md; use an explicit non-Claude path
when given. Inspect collisions and obvious related filenames only.

Include title/date/status Braindump, one-sentence core idea, a simple flow sketch
when it clarifies the idea, original context/pain, rough notes, and relevant attachments
or related links. Omit empty sections. Keep multiple ideas together unless asked to split.
If the same capture exists, append a dated update rather than overwrite it; do not
convert an existing PM analysis into a braindump.

No fit scores, competition research, effort estimate, ticket, or implementation.
Confirm the saved path briefly and resume the original task if this was an interruption.

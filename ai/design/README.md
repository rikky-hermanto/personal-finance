# Design — how screens look

- Rikky's standing UI corrections: [ui-rules.md](ui-rules.md). Read them before any UI change.
- Code conventions (shadcn/ui, Tailwind, React Query) live in `.claude/rules/frontend.md`.
- Living reference: the app itself. Run `docker-up`, then open http://localhost:8080/journey.

# Decide — hard calls

Questions that need a verdict before anything is built.

| Question | Skill |
|---|---|
| A focused technical decision, a design critique, tradeoffs, an ADR, or scaling | **consult** |
| Health of the existing codebase | **consult health [focus]** |
| Two written proposals head to head | **consult battle [A] [B]** |
| The direction itself is contested | **council** |
| Is this formula, rubric, or feature financially sound? | **cio** |
| Risk limits, sizing, honesty of a risk screen | **risk-officer** |
| Allowed in Indonesia? Disclaimers? Tax shown correctly? | **compliance** |
| Do users want it? Do competitors have it? | **pm-brainstorm** |

The money invariants (FIN-01 to FIN-06) live in `.claude/rules/finance-domain.md`; the formulas and tax tables in `docs/reference/finance-domain/`.

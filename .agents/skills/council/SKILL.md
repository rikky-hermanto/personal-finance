# council

Read [shared Codex workflow conventions](../../WORKFLOWS.md) before using this skill.

Apply five analytical lenses to the same question and evidence:
1. Contrarian: strongest countercase and overlooked failure.
2. First principles: objective, constraints, essential mechanism.
3. Expansionist: larger opportunity and a useful adjacent possibility.
4. Outsider: alternative domain analogy and assumptions insiders overlook.
5. Executor: smallest viable experiment, dependencies, and delivery reality.

Present concise arguments and disagreements, not fabricated conversations with real
experts or hidden reasoning transcripts. These can be evaluated locally; do not
claim five independent agents ran unless they did. Current delegation rules still apply.

Synthesize what changed, decisive factor, YES / NO / NOT YET / REFRAME, a concrete
recommendation, confidence, and evidence that would reverse it. Keep the user's
scope and actual constraints central. A verdict is not permission to implement,
publish, trade, or create tickets. Save requested output under docs/codex/reviews/.

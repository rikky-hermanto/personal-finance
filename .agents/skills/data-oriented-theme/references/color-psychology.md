# Functional color and density

Use neutral backgrounds to keep attention on the data. This is the project's design
convention, not a quantified claim about cognitive-load reduction or eye health.
Base reference palette: light canvas #F7F8FA, dark canvas #0F1117, surface white /
#1A1D27, foreground #111318 / #E8EAF0, muted #6B7280 / #9CA3AF, border #E4E6EB /
#2A2D3A, interactive blue #2563EB. Zen uses its own warmer overrides.

Functional colors distinguish positive/income, negative/expense, caution, and actions.
Preserve the application's learned semantics. Supplement color with labels, signs,
icons, or patterns; color associations are not universal and color blindness matters.
Keep competing accents limited while retaining useful chart series distinctions.

Measure contrast for actual foreground/background/opacity combinations instead of
repeating fixed contrast claims from a palette table. Muted metadata still needs to
be readable; do not assign unreadable gray to essential dates or IDs.

Use proximity and an 8px spacing rhythm to make related groups obvious. These are
layout conventions, not exact limits on human memory. Adjust density for the task,
viewport, and readability, and verify keyboard focus and light/dark modes.
